# Javadoc Fixer Maven Plugin

Maven plugin to automatically fix incomplete Javadoc in delomboked Java sources.

## Features

- ✅ Adds `/** Default constructor */` to constructors without Javadoc
- ✅ Adds complete Javadoc to `canEqual` methods (generated by Lombok @Data/@Value)
- ✅ Preserves existing complete Javadoc
- ✅ Thread-safe execution
- ✅ Detailed logging of fixes applied

## Usage

### Basic Configuration

Add the plugin to your `pom.xml` in the `release` profile (or wherever you use delombok):

```xml
<plugin>
    <groupId>com.weedow</groupId>
    <artifactId>javadoc-fixer-maven-plugin</artifactId>
    <version>${project.version}</version>
    <executions>
        <execution>
            <id>fix-javadoc</id>
            <phase>generate-sources</phase>
            <goals>
                <goal>fix-javadoc</goal>
            </goals>
        </execution>
    </executions>
</plugin>
```

### Configuration Options

| Parameter         | Type    | Default                               | Description                             |
|-------------------|---------|---------------------------------------|-----------------------------------------|
| `sourceDirectory` | File    | `${project.build.directory}/delombok` | Directory containing delomboked sources |
| `skip`            | boolean | `false`                               | Skip plugin execution                   |

### Example Configuration

```xml
<plugin>
    <groupId>com.weedow</groupId>
    <artifactId>javadoc-fixer-maven-plugin</artifactId>
    <version>${project.version}</version>
    <configuration>
        <sourceDirectory>${project.build.directory}/delombok</sourceDirectory>
        <skip>false</skip>
    </configuration>
    <executions>
        <execution>
            <id>fix-javadoc</id>
            <phase>generate-sources</phase>
            <goals>
                <goal>fix-javadoc</goal>
            </goals>
        </execution>
    </executions>
</plugin>
```

## How It Works

The plugin processes delomboked Java files and applies the following transformations:

### Default Constructors

**Before:**
```java
@java.lang.SuppressWarnings("all")
@lombok.Generated
public MyClass() {
}
```

**After:**
```java
/** Default constructor */
@java.lang.SuppressWarnings("all")
@lombok.Generated
public MyClass() {
}
```

### canEqual Method

**Before:**
```java
@java.lang.SuppressWarnings("all")
@lombok.Generated
protected boolean canEqual(final java.lang.Object other) {
    return other instanceof MyClass;
}
```

**After:**
```java
/**
 * canEqual method.
 * @param other Other.
 * @return true or false
 */
@java.lang.SuppressWarnings("all")
@lombok.Generated
protected boolean canEqual(final java.lang.Object other) {
    return other instanceof MyClass;
}
```

## Integration with Lombok

This plugin is designed to work seamlessly with the following Maven plugin chain:

1. **lombok-maven-plugin** (`delombok` goal) - Generates delomboked sources
2. **javadoc-fixer-maven-plugin** (`fix-javadoc` goal) - Fixes incomplete Javadoc
3. **maven-javadoc-plugin** - Generates Javadoc from delomboked sources

## Requirements

- Maven 3.9.0 or higher
- Java 17 or higher
